# Recursos do DANFSe

Recursos normativos utilizados pela implementação do DANFSe v2.0:

- Nota Técnica SE/CGNFS-e nº 008, versão 1.02, de 14/07/2026;
- logomarca horizontal oficial da NFS-e, publicada no Portal Nacional em 31/03/2026;
- `NFSe-ESQUEMAS_XSD-v1.01-20260209`, contendo os XSD 1.00 e 1.01;
- `ANEXO_A-MUNICIPIO_IBGE-PAISES_ISO2-v1.00-SNNFSe-20251210`, usado para gerar os mapas JSON offline.

Fontes oficiais:

- https://www.gov.br/nfse/pt-br/biblioteca/documentacao-tecnica/rtc/nt-008-se-cgnfse-danfse-20260714-v1-02.pdf
- https://www.gov.br/nfse/pt-br/biblioteca/documentacao-tecnica/documentacao-atual
- https://www.gov.br/nfse/pt-br/biblioteca/documentacao-tecnica/logos-da-nfs-e

Os arquivos JSON são artefatos derivados do Anexo A e devem ser regenerados quando o domínio oficial for atualizado.
